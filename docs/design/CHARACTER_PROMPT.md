# Character prompt template

Copy this into your preferred image tool. Replace the brackets. Generate the first pose, refine it, and then provide that image as the consistency reference for the next pose. This is a starting prompt, not a promise that any tool will return perfect dimensions or matching characters.

> Create an original pixel-art fitness avatar that represents me. Appearance: [skin tone, hair color/style, glasses or other details I choose]. Outfit: [top, shorts/leggings, shoes, accessories]. Palette: [colors]. Mood: [playful, determined, relaxed].
>
> Use crisp, chunky pixel shapes, limited shading and a readable silhouette inspired by classic handheld-game graphics, without copying any existing game character or franchise. Keep the face and body proportions consistent across all images. No logos, text, labels, borders, watermarks or extra characters.
>
> Make ONE full-body character in this pose: [pose from the list below]. Use a transparent background and a portrait 2:3 canvas. Leave space around the entire character, including weights, hands and feet. Target export: 320 × 480 pixels. Do not crop any limbs. The image must remain readable when displayed at about 46 × 72 pixels.

For subsequent poses, add:

> Use the attached original character as the identity reference. Preserve their face, hair, proportions, outfit and pixel style; change only the pose/expression. Do not add unrelated details from the reference sheet.

Pose prompts:
- Standing confidently, hands on hips.
- Holding two dumbbells at chest level.
- One-arm dumbbell curl, other hand resting on hip.
- Goblet squat holding one dumbbell in front.
- Standing with one arm raised in a confident gesture.
- Standing, flexing both arms, cheerful expression.

For the portraits, replace the full-body paragraph with:

> Make ONE square head-and-shoulders portrait of the same character, [calm friendly expression / joyful celebration]. Target export: 384 × 384 pixels. Use [a solid background color / transparent background]. Keep the face inside the frame with a little breathing room. No white border. It must be readable at 64 × 64 pixels.

## Export check

- Verify the actual exported canvas dimensions; resize with nearest-neighbor for pixel art, then pad/crop without stretching.
- Check actual alpha transparency. A painted checkerboard is not transparency.
- Confirm all poses look like the same person, at the same scale.
- Keep the full pose in frame and check it at phone size.
- Replace Lucie's example art before sharing your personalized fork. Keep your own source/prompt record and state how others may use your new artwork.
