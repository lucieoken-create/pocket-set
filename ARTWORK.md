# Artwork and personalization

Pocket Set's existing character was made with AI assistance as **Lucie's personal avatar**. It is included as an example of the design and implementation. The intended customization is to make a character that represents **you**, rather than reuse Lucie's identity in your own shared app.

The MIT license covers the application code. This repository does not extend that license to the personal character artwork or grant additional reuse permission for it. Create your own original assets for a personalized/public fork, and state the terms for your own artwork. This note is not a claim of exclusive rights over AI-generated output or a substitute for checking rights in any references you use.

This applies to `public/assets/characters/*.png`, the original `sprites.png` and `portraits.png` sheets, and the example images reproduced in `docs/design/reference-sheet.png`. The reference sheet is a creative guide, not a required technical sprite layout.

The [Make it yours guide](docs/design/MAKE_IT_YOURS.md) includes a file map and a [copyable prompt](docs/design/CHARACTER_PROMPT.md). No Barry's logos or existing game-franchise characters are required or encouraged. This is an independent project, not affiliated with or endorsed by Barry's.

Fonts, icon source and bundled dependencies have separate licenses documented in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
